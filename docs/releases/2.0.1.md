# BFD Windows Service v2.0.1

This patch release corrects deployment and telemetry defects found in the
repository-wide code, test, and documentation alignment audit.

## Fixes

- Give S-BFD reflector requests and replies separate firewall rules covering
  every supported nonzero initiator source port except 7784. Classical BFD
  retains its dynamic-source-port restriction. The setup bundle now installs
  five scoped UDP rules.
- Preserve the configured interface scope in both link-local IPv6 endpoints
  returned through session-status RPC.
- Document and verify the native x64 Visual C++ runtime prerequisite for loose
  console deployments. Correct the receive/wait versus send-error recovery
  descriptions and the broker's authenticated local RPC terminology.

## Validation and packaging

- Reject packaging when either executable lacks a native MSVC toolset receipt
  or was built with a toolset newer than the embedded Microsoft runtime.
- Test upgrade from the published v2.0.0 bundle, failure rollback to its exact
  executable bytes and product registration, preservation of typed configuration,
  service security policy and logs, repair, and mutual service RPC authentication.
- Add an installed-reflector source-port boundary regression and a stateful
  S-BFD initiator fuzz target covering probe correlation, loss, replay, live
  timing changes, Poll/Final, and maintenance.

## Compatibility and version selection

The latest published baseline is v2.0.0. The complete change set fixes existing
behavior and strengthens validation without adding a product feature or changing
the supported CLI, registry schema, Rust public API, RPC wire layout, service
identities, or Windows support. The firewall change restores the documented
S-BFD transport contract. These compatible fixes warrant the patch increment
to v2.0.1 under the repository's release policy.

Upgrade with `BfdWinService-2.0.1-x64-setup.exe`; existing configuration and logs
are retained. Distribution remains the offline setup executable and its SHA-256
checksum. The embedded x64 Visual C++ runtime remains 14.51.36247.0. Upgrade
validation covers v2.0.0; it does not certify every historical installer or real
router interoperability.
